# ArboHub

Sistema interno de automações desenvolvido para apoiar atividades do setor de vigilância em saúde.

## Objetivo

Centralizar e automatizar tarefas realizadas em diferentes sistemas, como:

- SINAN
- GAL
- relatórios
- organização de arquivos
- mapas e geoprocessamento

## Situação do projeto

Projeto em fase inicial de desenvolvimento.

## Tecnologias previstas

- Python
- CustomTkinter
- Playwright
- Pandas
- SQLite
- Git

## Estrutura inicial

- `app/`: código principal do sistema
- `docs/`: documentação
- `logs/`: registros de execução
- `scripts/`: scripts auxiliares
- `tests/`: testes
- `main.py`: ponto de entrada do programa

## Segurança

Este projeto não deve armazenar ou publicar dados pessoais, credenciais, bancos do SINAN, GAL ou outros dados sensíveis.
